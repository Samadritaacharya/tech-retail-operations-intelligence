# Retail Operations web design

The interactive app uses dark editorial surfaces, magenta/amber commerce accents, restrained glass, evidence-first cards, and a flowing R3F system map.

Taste Skill informs the audit-first hierarchy; awesome-design-md informs explicit visual constraints; ShaderGradient supplies ambient motion; liquid-glass-js is a visual reference only; liquid-logo is a shader-concept reference only. The center orb uses original GLSL. Motion honors reduced-motion; WebGL has a fallback; no model key, DB, login, analytics service, or paid API is required.
